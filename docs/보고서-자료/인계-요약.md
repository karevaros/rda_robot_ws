## 4. 🔴 회피 알고리즘 검증 — 결론이 뒤집힌 사례다

**이 절을 잘못 옮기면 보고서가 사실과 달라진다.** 근거대장 **10장** 전문 참조.

### 4-1. 수치가 두 벌이다

| | 회피 있음 | 정면 직선(회피 없음) | 관절보간(회피 없음) |
|---|---|---|---|
| **1차**(08-21 오전 · 18런) | 0.05 % | **1.80 %** | 5.51 % |
| **재측정**(08-21 오후 · 38런) | **0.12 %** | **0.00 %** | **3.58 %** |

* **보고서에 싣는 것은 재측정**이다. 1차는 *조건이 결론을 바꾼 사례*로만 인용할 것.
* 1차가 달랐던 이유 = 직선을 열매 앞 12 cm 에서만 시작하고 **그 앞을 관절보간으로 갔다**.
  사용자가 정의한 "캐노피 밖에서부터 직선"으로 바로잡자 결과가 뒤집혔다.

### 4-2. 무엇을 주장할 수 있고 무엇을 주장할 수 없나

| | |
|---|---|
| ✅ 주장 가능 | ① 관절보간 대비 접촉 **3.58 % → 0.12 %** ② 정면 자세를 못 찾는 열매의 **대안 확보** |
| ✕ 주장 불가 | "회피가 접근 경로의 충돌을 막았다" — **정면 직선이 0.00 %** 였다 |
| ✕ 반대로도 불가 | "회피는 불필요하다" — 잎이 있는 실제 캐노피는 다르다 |

**왜 그런가**: 이 온실 모델은 **통로 쪽으로 캐노피가 없다**(잎·곁순이 모델에 없다 — 사용자
지시로 제외). 행 법선으로 곧게 들어가면 경로상에 걸릴 것이 없다. 접촉을 만드는 것은
'경로'가 아니라 **'자세'** 다.

### 4-3. 인용 조건 (빼면 조건 없는 수치가 된다)

* 🔴 **팔 베이스 +500 mm 시험 구성**에서만 성립 — **채택하지 않기로 결정된 구성**(08-18).
  기본 구성 + 현실 화방높이는 도달 열매 **0/74** 라 같은 비교가 성립하지 않는다.
* **회피가 접촉 0 을 보증하지 않는다** — 1런에 스침 2점, **원인 미규명(검증 부채)**.
* 열매를 충돌객체로 켜면 세 방식 모두 크게 늘고(4.76~11.78 %), 접촉 상대 대부분이
  **손에 든 열매 ↔ 같은 화방 이웃 열매** = 경로가 아니라 **화방 구조·파지 방식** 문제.

## 5. 🔴 작물 모델 정밀화 — "사진으로 치수를 쟀다"가 아니다

* **사진이 정한 것은 구조뿐**이다(화방 줄기가 열매 위를 지난다 · 열매가 소과경으로 매달린다).

  절대 치수는 기존 근거(AIHub · STEP 실측) 그대로.
* 표기: **"사진으로 형상을 교정했다"** ○ / **"사진에서 치수를 실측했다"** ✕.
* 반영 = 화방 줄기를 **열매 윗면**으로(종전엔 열매를 관통) · **소과경 53개** 신설 ·
  상세 장면 **187 → 240개**. **정본 장면 전개는 바이트 동일**(187개) ⇒ 기존 검증 수치 무영향.
* **넣지 않은 것 3건은 이유가 서로 다르다** — 잎(**사용자 지시로 제외**, 한계 남음) ·
