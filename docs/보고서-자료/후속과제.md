## 🟡 남은 작업

> ✅ 2026-08-16 에 해소된 항목은 아래 "해소됨" 표로 내렸다 — **남은 것만 번호로 둔다.**

1. **접근 축 캡슐/원뿔** — 현재 구(ρ=15.7cm) 영역은 이웃 화방까지 무시하게 된다.
   근거 2건 확보됨. `publish_targets:=true` 조건에서 재측정 필요.
2. **RealSense TF 경계 결정** — URDF 는 마운트까지, 내부는 드라이버 TF. 안 정하면 **이중 발행**.
3. **`mimic` 대응** — USD·Unity URDF Importer 양쪽 다 mimic 이 없어 손가락 관절이 독립.
   컨트롤러가 같은 값을 주거나(Unity 쪽에서 가능) 시뮬레이터의 mimic/coupled joint 로 묶어야 한다.
   ※ Unity 는 실행 검증됐으므로 여기서 확인 가능. Isaac 쪽은 **범위 밖**이라 미해결로 남긴다.
4. **Unity 물리 거동 검증**(선택) — 미러 구성에서는 중력·로봇 콜라이더를 껐으므로
   **중력에서의 팔 처짐 = 07-30 유도 effort 값의 첫 실전 시험**이 3종 어디에서도 아직 안 이뤄졌다.
   Isaac 이 범위 밖이 되면서 **이 시험이 가능한 곳은 Unity 뿐**이 됐다.
