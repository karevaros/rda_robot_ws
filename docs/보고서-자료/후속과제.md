## 🟡 남은 작업

1. **3종 비교표**(M4 마감 조건) — Unity 실행 결과가 나와야 3종 비교가 성립.
2. **데모 캡처** — `docs/images/` 에 현재 6장뿐. 6주차 execute·GUI 패널·재계획 발화 장면 없음.
3. **접근 축 캡슐/원뿔** — 현재 구(ρ=15.7cm) 영역은 이웃 화방까지 무시하게 된다.
   근거 2건 확보됨. `publish_targets:=true` 조건에서 재측정 필요.
4. **RealSense TF 경계 결정** — URDF 는 마운트까지, 내부는 드라이버 TF. 안 정하면 **이중 발행**.
5. **`mimic` 대응** — USD·Unity URDF Importer 양쪽 다 mimic 이 없어 손가락 관절이 독립.
   컨트롤러가 같은 값을 주거나 Isaac mimic joint 로 묶어야 한다.
