| # | 결함 | 증상 | 원인 |
|---|---|---|---|
| ① | `manifest.json` 에 `com.unity.modules.imageconversion` 누락 | URDF Importer 가 `error CS1061` 로 컴파일 실패 → 배치 전체 사망 | 패키지의 `UnityMeshImporter` 가 `Texture2D.LoadImage` 사용 |
| ② | 리플렉션 호출 2중 오류 | `TargetParameterCountException`, 고쳐도 임포트가 **조용히 아무 일도 안 함** | `Create` 는 인자 **4개**(리플렉션은 C# 기본값을 안 채운다) + **`IEnumerator<GameObject>` 코루틴**이라 호출만으로는 실행되지 않는다(`MoveNext` 필요) |

⚠ **설치 과정에서 막힌 지점 2개**(재현 대비).
· **`.alf → .ulf` 수동 활성화는 폐지됐다** — Unity 페이지 원문 "Unity no longer supports manual
  activation of Personal licenses." ⇒ Personal 은 **Hub 온라인 로그인만** 가능.
· **`unityhub://` URL 스킴 핸들러 미등록** — `.deb` 를 `dpkg -x` 로 풀기만 해 후처리가 안 돌았고,
  OAuth 복귀가 브라우저에서 "No Apps available" 로 끊겼다. `~/.local/share/applications` 에
  desktop 파일을 두고 `xdg-mime default unityhub.desktop x-scheme-handler/unityhub` 로 해소.

⚠ **여기까지가 보증하는 범위** — '같은 로봇·같은 장면을 Unity 가 우리 의도대로 연다'까지다.
**물리 거동(중력 처짐·드라이브 게인·충돌 응답)은 여전히 미검증**이며, `mimic`(rg2_finger_joint2)은
URDF Importer 가 무시하므로 손가락 관절이 독립이다.

```bash
ros2 launch rda_robot_moveit_config perception_demo.launch.py \
  execute:=true run_demo:=true harvest_all:=true harvest_max:=2 harvest_remove:=true \
  gui:=true rviz:=true sensors:=d435i world:=greenhouse detect:=true
```

캡처 도구는 신규 `docs/scripts/capture_window.py`(PyQt5 `QScreen.grabWindow`) — 이 PC 에
